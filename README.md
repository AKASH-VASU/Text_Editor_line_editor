# 📝 Text Editor in C

A command-line based text editor developed in C to understand file handling, dynamic memory, data structures, cursor movement, and modular programming.

## ✨ Features

- Create and edit text files
- Open and read existing files
- Insert and delete characters
- Cursor movement and navigation
- Undo and redo operations
- File save functionality
- Command-line interface
- Modular code using multiple source files

## 🚀 Project Phases

### 🔹 Phase 1 – Basic Text Editor
- File creation and opening
- Character insertion and deletion
- File saving
- Dynamic memory management
- Undo and redo using data structures
- Modular implementation using DLL

### 🔹 Phase 2 – Cursor & Navigation
- Cursor movement
- Line and character navigation
- Editing text at the cursor position
- Improved user interaction

## 🛠️ Technologies Used

- **Language:** C
- **Concepts:** File Handling, Pointers, Dynamic Memory Allocation, Data Structures
- **Data Structures:** Linked List / Stack
- **Build Tool:** GCC
- **Platform:** Linux
- **Version Control:** Git & GitHub

## 🧠 Key Concepts Implemented

- Structures and pointers
- Dynamic memory allocation
- File I/O
- Linked Lists
- Stack-based Undo/Redo
- Function pointers
- Modular programming
- Command-line interface

## 🎯 Learning Outcomes

This project provided hands-on experience in developing a real-world C application while strengthening knowledge of pointers, dynamic memory allocation, file handling, data structures, modular programming, and problem-solving.
